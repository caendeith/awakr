Всё, что должен уметь будильник, и ничего из того, чем обычно грешат приложения-будильники

Ни баннера, ни межстраничной рекламы, ни экрана подписки — и никакой сети, чтобы «звонить домой».

🔒

Без разрешения INTERNET

Приложение физически не может никуда подключиться. CI роняет сборку, если в объединённом манифесте появляется INTERNET.

🧩

Миссии — это плагины

Математика, сканирование кодов, тряска и ввод текста — отдельные Gradle-модули за одним интерфейсом MissionPlugin. Новая миссия — это один небольшой PR.

⏰

Действительно надёжно

API будильника, точное планирование, перепланирование после перезагрузки, обновления приложения и смены часового пояса, звонок на весь экран поверх экрана блокировки.

🎵

Своя музыка

Семь встроенных сигналов или любой аудиофайл из памяти: он копируется в приложение и звучит, даже если удалить оригинал.

🌗

Обе темы

Тёмная по умолчанию, светлая по желанию или как в системе. Янтарь на угле, анимация и типографика — прямо из Material 3.

✋

Сделано для сонных рук

Долгое нажатие выделяет несколько будильников сразу, действие свайпа настраивается, есть режим перестановки с перетаскиванием и отмена после удаления.

⏳

Лимит отложек

Задайте, сколько раз будильник можно отложить. После лимита кнопка «Отложить» исчезает, и остаётся только миссия.

📋

О пропущенных будильниках сообщается

Если телефон был выключен или приложение принудительно остановили, карточка и уведомление скажут, что будильник не прозвенел — один раз, а не при каждом запуске.

🔗

Три миссии подряд

До трёх разных миссий в цепочке на одном будильнике. Каждый этап даёт новое задание, а будильник замолкает только после последнего.

📈

Видно, как вы просыпаетесь

Каждый звонок пишется в журнал. Экран статистики показывает стрик за 7 или 30 дней, число выключений, отложек и пропусков и среднее время подъёма.

👀

Проверка пробуждения

Необязательное напоминание через 100 секунд после выключения - для утр, когда «я встал» оказывается неправдой.

Восемь способов доказать, что вы проснулись

У каждой миссии свои настройки в редакторе будильника. Отключите плагин — и будильник предложит отключить его удержанием, а не будет звонить бесконечно.

Математика math

Лёгкие, средние или сложные примеры; от 1 до 5 верных ответов подряд, прежде чем будильник сдастся.

Код code

Сканируйте QR-код или настоящий товарный штрихкод: EAN-13, EAN-8, UPC-A, Code 128. Сгенерируйте свой код или привяжите любой найденный — подойдёт товар с полки.

Тряска shake

Трясите телефон от 10 до 100 секунд, пока заполняется кольцо прогресса.

Ввод текста typing

Введите заданную фразу точно. Никаких «1234» и случайных отключений.

Память memory

Сетка 4x4 вспыхивает короткой последовательностью; повторите её по порядку.

Цвет color

Найдите плитки заданного цвета среди отвлекающих.

Приседания squat

Настоящие приседания по акселерометру - без камеры и лишних разрешений.

Шаги step

Пройдите заданное число шагов. Считается по акселерометру, а не по счётчику шагов.

🛠 Всё перечисленное — плагины с декларативным манифестом: id, локализованное имя, версия, возможности, нужные разрешения и поля настроек. Реестр генерируется на этапе сборки через KSP, поэтому здесь нет ни рефлексии, ни динамической загрузки кода.

Как это выглядит

Янтарь на угле, моноширинные цифры для обратного отсчёта, действия, до которых легко дотянуться одной рукой.

Установка

Возьмите подписанный APK из последнего релиза или соберите сами. Ключ релиза не хранится в репозитории, поэтому самостоятельно собранные сборки устанавливаются параллельно с релизной.

Из APK

Скачайте Awakr-1.4.0.apk, разрешите установку из неизвестных источников, откройте файл.

# или по USB
adb install -r Awakr-1.4.0.apk

Из исходников

JDK 17, Android SDK с platform 36 и build-tools 36.0.0.

git clone https://github.com/caendeith/awakr.git
cd awakr
echo "sdk.dir=$HOME/Android/Sdk" > local.properties
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
✅ После первого запуска приложение проведёт вас по разрешениям, которые действительно могут понадобиться: уведомления (API 33+), точные будильники (API 31+), камера (только для миссии «Код») и микрофон (только пока вы записываете свой звук). Больше ничего не запрашивается.

Под капотом

Один модуль приложения, несколько основных модулей, SDK плагинов и четыре модуля миссий. Room для хранения, DataStore для настроек, CameraX + ZXing для кодов, без сервисов Google Play.

Kotlin 2.2.21 · Compose M3

Material 3 с небольшой собственной дизайн-системой: карточки, «таблетки», моноширинный текст времени, янтарный акцент.

AGP 8.13.2 · Gradle 8.14.6

compileSdk 36, targetSdk 36, minSdk 26 — от Android 8.0 до 17.

Room 2.8.5

Будильники, журналы будильников и состояние каждого плагина, с явной миграцией v1→v2 для звуков и порядка.

CameraX 1.5.3 + ZXing 3.5.4

Декодирование живого превью в фоновом потоке, поворот кадра обрабатывается вручную, юнит-тесты для повёрнутых кадров.
